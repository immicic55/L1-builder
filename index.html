The philosophy↙

Understand the core.

around it.

A system is easier to make your own when you know what holds it together. LTR starts with a deliberate base: musl, dash and s6. Source-built, with the pieces in plain sight.

GNU tools are permitted on the build host. The target image excludes GNU tools and runtime libraries. A small foundation, with room for your decisions.

A lean foundation.

musl provides the C standard library at the heart of the target system. LTR builds its core around this compact foundation, with no GNU runtime libraries in the target image.

Before you boot

What’s in the image? +

Linux, musl, BusyBox, dash, s6, Limine, LPM, wired DHCP, curl/LibreSSL, OpenSSH, console Vim, libarchive, selected firmware and BIOS/UEFI installation tools.

What’s still in development? +

This is a boot-core development image. Wi-Fi/iwd, mdevd, privilege tools and the on-target compiler SDK still need integration. The host bootstrap currently targets Artix.

How do I test it? +

After building, run python3 tools/boot_test.py for the BIOS smoke test, or add --uefi for UEFI. The live image uses an unauthenticated local development console; no SSH server is enabled.
