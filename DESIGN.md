# Website design

Plain HTML, CSS and JavaScript, as requested. Aerospace-inspired Astra/Artemis direction: charcoal, warm off-white, dark-orange geometric solids, broad negative space, strong typography and orbital linework. The experience introduces the distro through three CSS 3D blocks representing musl, dash and s6. The logo derives from the existing fetch command.

The opening three-box scaling animation lasts 2.4 seconds. Scroll moves the assembly into an exploded view without trapping native scrolling. Direct controls support pointer, touch and keyboard users. System reduced motion takes precedence over the local motion toggle. All text and navigation remain ordinary HTML; the sculpture is decorative.
